Interpretation
--------------
Both runs completed the SCTP association, so the AMF address, port, and N2
transport were working. Changing only Mobile Network Code 70 to 71 changed the
NGAP outcome from NG Setup Response to NG Setup Failure. Restoring Mobile
Network Code 70 restored NG Setup success.

Review
------
The reviewed captures retain only association, NG Setup, acknowledgement, and
controlled shutdown packets. Periodic SCTP heartbeats were removed. The files
contain synthetic PLMN values, local loopback endpoints, a synthetic gNB
identity, Tracking Area Code 1, and Slice/Service Type 1. They contain no UE
NAS message, subscriber identity, permanent authentication key, or OPc.
