Interpretation
--------------
Both runs used the same Public Land Mobile Network and completed the SCTP
association. The failure run advertised Tracking Area Identity 999-70-2, but
the AMF serves 999-70-1. The AMF returned NG Setup Failure. Restoring only
Tracking Area Code 1 changed the outcome to NG Setup Response.

The standardized cause alone does not distinguish a global PLMN mismatch from
an unsupported served tracking area. The NG Setup Request fields and AMF log
provide that distinction.

Review
------
The reviewed captures retain only association, NG Setup, acknowledgement, and
controlled shutdown packets. Periodic SCTP heartbeats were removed. The files
contain synthetic PLMN and tracking-area values, local loopback endpoints, a
synthetic gNB identity, and Slice/Service Type 1. They contain no UE NAS
message, subscriber identity, permanent authentication key, or OPc.
